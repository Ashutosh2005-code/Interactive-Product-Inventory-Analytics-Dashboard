\# Interactive Product Inventory \& Analytics Dashboard



A responsive product inventory dashboard built using HTML, CSS, and JavaScript. This project demonstrates core JavaScript concepts through an interactive interface for managing products and viewing inventory analytics.



\## Features



\- \*\*Add Products:\*\* Enter product names and prices using prompts.

\- \*\*Product Validation:\*\* Validate product details using conditional statements.

\- \*\*Category Badges:\*\* Classify products into Budget, Standard, and Premium categories.

\- \*\*Inventory Statistics:\*\* Calculate total inventory value, product count, and average price.

\- \*\*Affordable Products:\*\* Filter products priced below $200.

\- \*\*Formatted Reports:\*\* Generate uppercase product reports with formatted prices.

\- \*\*Tax and Discount Calculations:\*\* Demonstrate arrow functions and local scope.

\- \*\*Responsive UI:\*\* Clean dashboard interface for different screen sizes.
